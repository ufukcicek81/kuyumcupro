# Asil Kuyumcu Pro v6.12 — Barkod / Etiket Yazıcı Merkezi

Bu sürüm barkod basma ve yazıcı ayarlarını gerçek kullanım için toparlar.

## Barkod / Etiket Merkezi
- Barkod, kısa kod, stok kodu ve ürün adına göre etiket arama
- Görünenleri seç / seçimi kaldır
- Seçilen etiketleri toplu yazdırma
- Test etiketi
- Etiket önizleme
- Etiket üstünde gösterilecek alanları aç/kapat
  - ürün adı
  - ürün kodu
  - ayar
  - gram
  - stok/Pusula kodu
  - satış HAS
  - TL fiyat
  - model
- Maliyet bilgisi etikete basılmaz

## Yazıcı Ayarları
- Tarayıcı yazdırma modu
- QZ Tray doğrudan yazıcı modu
- Yazıcı adı seçimi / bağlı yazıcıları listeleme
- 203 / 300 / 600 DPI
- Etiket genişlik / yükseklik (mm)
- üst / alt / sağ / sol boşluk
- yazı ölçeği
- kopya sayısı
- dikey / yatay baskı
- Rulo / Tek Etiket modu
- A4 etiket sayfası modu
- A4 sütun sayısı, etiket aralığı ve kenar boşluğu

## Otomatik Etiket
Açık stoktan barkodlu ürüne aktarım yapılırken “Barkodu oluşturunca etiketi yazdır” seçeneği vardır. Varsayılan davranış Yazıcı Ayarları içinden açılıp kapatılabilir.

## QZ Tray
Doğrudan termal yazıcıya gönderim için QZ Tray entegrasyonu hazırdır. QZ Tray bilgisayarda çalışıyorsa “QZ Bağlantısını Test Et” ve “Yazıcıları Bul” düğmeleri ile yazıcı seçilebilir.

Tarayıcı yazdırma modu eklenti gerektirmez. Epson/Laser/A4 etiket sayfaları için A4 modu daha uygundur.
