# Asil Kuyumcu Pro v4.9

- Kasa isimlerindeki **Merkez** ön eki kaldırıldı.
- Fiziksel **HAS Kasa** tamamen kaldırıldı; HAS stok/cari değer birimi olarak izleniyor.
- Kasa listesi TL, USD, EUR, GBP, CHF gibi gerçek kasa hesaplarını gösteriyor.
- Satış ekranına **Satış Geçmişi** eklendi.
- Geçmiş satışlar aranabilir, görüntülenebilir, güvenli biçimde düzeltmeye açılabilir veya iptal edilebilir.
- Düzeltme/iptalde bağlı stok, cari, kasa/POS ve takas hareketleri geri alınır.
- Düzeltmeye açılan fiş aynı belge numarasıyla yeniden onaylanır.
